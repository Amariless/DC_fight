# image-targets/

Esta carpeta la gestiona normalmente el panel **Image Targets** del editor
de 8th Wall Studio (subes ahí las fotos y él las coloca aquí). Se
necesitan 8 imágenes con estos nombres exactos (deben coincidir con el
campo "Image Target" de cada entidad en `src/.expanse.json`) — **ya están
subidas**:

- `mapa` — foto/arte completo del tablero (`mapa.png`, horizontal:
  zona Jugador 1 a la izquierda en azul, zona Jugador 2 a la derecha en
  rojo/morado).
- `card-batman`, `card-superman`, `card-wonderwoman`, `card-flash`,
  `card-cyborg`, `card-joker`, `card-harley` — el frente de cada carta.

Usa imágenes con buen contraste y detalle (evita fondos lisos o
simétricos) para que el tracking sea estable.
